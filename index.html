PrivBeaver Extension

A DBeaver plugin that brings differential privacy to SQL query execution, protecting sensitive data while maintaining data utility for analysis. This plugin integrates the three following tools :

Qrlew DOP-SQL PG Anonymizer

Important: The execution of SQL queries using the PG Anonymizer tool requires a PostgreSQL Anonymizer extension properly installed and configured.

PostgreSQL Anonymizer only works on Linux and is not supported on Windows or macOS. Please refer to the official documentation for more information.

Installation Steps

  1. Open DBeaver
  2. Go to Help → Install New Software
  3. Click Add
  4. Enter:
    • Name: DBeaver Privacy Extension
    • Location: Copy the URL above
  5. Click Add
  6. Select DBeaver Privacy Extension
  7. Click Next → Next → Finish
  8. Restart DBeaver

Usage

  1. Write your SQL query in DBeaver's SQL Editor
  2. Go to Window → PrivBeaver
  3. Choose a tool and set parameters
  4. Click Execute Privacy Query
