🚀 Installation Steps

  1. Open DBeaver
  2. Go to Help → Install New Software
  3. Click "Add"
  4. Enter:
    • Name: DBeaver Privacy Extension
    • Location: Copy the URL above
  5. Click OK
  6. Select "DBeaver Privacy Extension"
  7. Click Next → Next → Finish
  8. Restart DBeaver

  • 🔒 Differential Privacy: Protect sensitive data in query results

  • ⚡ DOP-SQL Support: Differentially private SQL execution
